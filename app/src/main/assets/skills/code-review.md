# 代码审查技能

## 流程
1. 先用 fs_read 或 shell_exec(git diff) 读完整改动，再下结论，不凭片段猜测。
2. 按优先级输出：正确性 > 安全 > 并发与资源 > 可读性。
3. 每条问题给出：位置、原因、修改建议。

## 检查清单
- 空值、空列表、0、负数、超大输入
- 异常路径是否有处理与提示
- 资源是否释放（流、协程、线程、文件句柄）
- 外部输入是否校验（路径、URL、命令参数）
- 密钥是否硬编码
- 是否破坏已有行为

## 输出约定
只报告确认存在的问题；不确定的标注“待验证”并说明验证方法。
